# 실제 공시 XML 정제 오류 수정

검증일 2026-10-31. 과거 실패 기록과 원본은 변경하지 않고 별도 결과를 저장했습니다.

## 원인과 수정 범위

삼성전자·SK하이닉스의 OpenDART 원문에는 XML 마크업과 함께 다음과 같은 이스케이프되지 않은 본문 문자가 있었습니다.

- 회사명과 신용평가사 이름의 `R&D`, `SK E&S`, `S&P`
- `< TV 시장점유율 추이 >` 같은 제목
- `<삭제 2012.3.5>`, `<평가항목>`, `<ACI 세미나>` 같은 본문 표기

엄격한 XML 파서는 이를 엔티티 또는 태그로 해석해 `invalid token`이나 태그 불일치로 중단했습니다. `clean_xml()`이 먼저 원문을 그대로 파싱하고, 실패했을 때만 위 유형의 본문 문자를 이스케이프하도록 수정했습니다. 원본 파일은 변경하지 않습니다.

모든 파싱 오류를 HTML 복구 모드로 넘기지 않습니다. 기존 엔티티, CDATA·주석·처리 지시문을 보존하며, DTD/외부 엔티티, 알 수 없는 엔티티, 유효하지 않은 문자 참조, 임의로 깨진 태그 구조는 계속 거부합니다. 한글·영문 꺾쇠 표기는 원본에서 확인한 제한된 목록으로 처리합니다. 다른 기업·문서에서 새로운 표기를 만나면 추가 검증이 필요합니다.

```powershell

```

## 남은 과제

새로 수집한 SK하이닉스 2024 공시 833개 청크에서 R03·R09·R13을 실제 DART 조회 및 OpenAI 인용 선택까지 실행했습니다. 3개 모두 실행 완료, 채택 인용은 각각 1·3·0개였으며 4개 인용은 저장 청크와 일치했습니다. 이는 의미적 정확도 점수가 아닙니다. R03은 당기 AI 수요·실적에 대한 근거 후보였고, R09는 제품 구성과 높은 ASP 제품 판매를 설명하지만 가격 변화 자체의 효과를 충분히 분리하지 못합니다. R13은 정확한 이익 기여 비율을 생성하지 않았습니다. 이 판단도 Codex의 부분 검토이며 사람 정답을 대체하지 않습니다.

이번 수정은 실제 입력을 막던 정제 회귀를 해결한 것입니다. RAG 전체 24문항의 사람 정답 검토, 검색 성능 개선, 다른 기업·문서 형식 확대는 별도 과제입니다. 기존 재무 12/12·비율 17/17 및 RAG Baseline 기록은 이전 실험으로 보존합니다.
