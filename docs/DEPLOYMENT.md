# 실행 및 배포 준비 가이드

현재 배포 상태: **로컬 실행 검증용**, 외부 공개 배포하지 않음. Dockerfile/CI 미구현.
사용자의 우선순위에 따라 실제 P0 검증 전 P1을 진행하지 않았다.

## 로컬 프로세스

README의 두 명령으로 FastAPI(8000)와 Streamlit(8501)을 실행한다.
둘 다 `127.0.0.1`에 바인딩하며 UI는 `FINSIGHT_API_URL`로 API를 찾는다.
`scripts/smoke.py`는 별도 포트 18000/18501에서 서버를 실행해 검사 후 종료한다.
Mock 데이터도 명시적으로 표시되므로 키 없는 면접 시연에 사용할 수 있다.

## 실제 모드 전환

1. `.env.example`을 `.env`로 복사하고 공급자 키를 설정한다.
2. `FINSIGHT_MODE=live`로 변경 후 서버를 재시작한다.
3. 공시 수집 CLI로 질문 대상 연도의 문서를 저장한다.
4. `RUN_LIVE_TESTS=1`로 명시적 연동 테스트를 수행한다.
5. 실제 수치/링크를 원문과 대조하고 검증 문서에 날짜와 증적을 남긴다.

재무 조회만 필요하면 OpenAI 키 없이 live 실행 가능하다. 공시 수집/검색/근거 선택은 OpenAI 키가 필요하다.
API 키 발급/결제 설정을 이 프로젝트가 자동으로 수행하지 않는다.

## 향후 외부 배포 설계

- Python 3.11 이미지와 고정된 검증 의존성으로 빌드한다.
- FastAPI/UI를 별도 프로세스로 실행하고 API는 내부 네트워크에 둔다.
- 플랫폼 secret store에서 키를 주입한다. 이미지·클라이언트·Git에 포함하지 않는다.
- `CHROMA_PATH`에는 영속 볼륨을 마운트하고 백업/갱신 정책을 정한다.
- 공개 접근 전 인증, HTTPS, 서버 측 공유 호출량/비용 한도를 구현한다.
- 최소 `/health`와 실제 질의 smoke를 실행하되 health 응답은 공급자 연결 성공 증명이 아니다.
- 데이터 이용 조건과 외부 임베딩 서비스로의 문서 전송 범위를 확인한다.

이 항목들은 배포 완료 내역이 아니라 P1 준비 사항이다. 외부 배포 및 GitHub push에는 별도 승인이 필요하다.

## Windows 실행 환경 문제

샌드박스에서 asyncio의 로컬 socketpair 생성이 차단되면 FastAPI TestClient가 대기할 수 있다.
일반 로컬 터미널에서 실행하거나 허용된 환경의 로컬 소켓 권한으로 테스트한다.
임시 경로 접근 오류 시 `TEMP`/`TMP` 또는 pytest `--basetemp`를 접근 가능한 프로젝트 경로로 지정한다.
Chroma의 Windows mmap 파일은 프로세스 종료 전 삭제하지 않는다. 평가 DB는 `data/evaluations/`에 남는다.
