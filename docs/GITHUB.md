# 저장소에 올리는 것과 올리지 않는 것

## 올리는 것

소스 코드, 테스트, 문서, `.env.example`(키는 빈 값), 의존성 목록, 그리고 `evaluation/`의 실행 결과입니다. `evaluation/`에는 재현에 필요한 재무 수치와 공시 발췌문이 들어 있습니다.

공개용 JUnit 기록은 hostname을 지우고 테스트 경로를 저장소 기준 상대 경로로 바꿨습니다. 테스트 결과와 수치는 그대로입니다. 2026-10-29 Baseline의 XML 수집 실패 기록은 개선 전 상태를 보여 주는 자료라서 남겨 뒀고, 수정 후 결과는 [XML 수정 기록](XML_REPAIR.md)에 따로 있습니다.

## 올리지 않는 것

`.gitignore`로 다음을 제외합니다.

- 실제 `.env`, 가상환경, 캐시, 빌드 결과, 로그
- `data/`의 공시 원문, 로컬 DB, 벡터 DB
- 인증서, 로컬 도구 설정

새 실행 결과를 `evaluation/`에 추가할 때는 API 키, 인증 쿼리 문자열, 개인 경로, 필요 없는 원문 전체가 들어가지 않았는지 확인합니다. 키가 실수로 올라갔다면 `.gitignore`에 추가하는 것으로는 부족하고, 그 키를 폐기하고 새로 발급받아야 합니다.
