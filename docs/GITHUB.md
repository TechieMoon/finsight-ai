# GitHub 공개 준비

소스 코드, 테스트, 문서, `.env.example`, 의존성 목록과 `evaluation/`의 검증 근거를 공개합니다. `.env.example`의 API 키는 빈 값으로 유지합니다.

`.gitignore`는 실제 `.env`, 가상환경, 캐시, 빌드 결과, 로그, 로컬 DB, `data/`의 공시 원문·벡터 DB, 인증서 및 로컬 도구 설정을 제외합니다. 제외는 파일을 삭제하지 않으며, 이미 커밋한 파일이나 과거 기록에서는 제거하지 않습니다.

## GitHub Desktop에서 최초 게시

1. 이 폴더는 정리 당시 Git 저장소가 아니었습니다. **File → Add local repository**에서 이 폴더를 선택하고, 저장소가 없다는 안내에서 **create a repository here**를 선택합니다. 최종 경로가 현재 `finsight-ai` 폴더인지 확인합니다. 기존 README와 `.gitignore`를 유지하세요.
2. **Changes**에서 `.env`, `.venv/`, `data/`, `.tmp/`가 없는지 확인합니다. 소스·문서·테스트·평가 결과만 커밋합니다.
3. 최초 게시에는 **Publish repository**를 사용합니다. 공개 포트폴리오로 게시하려면 비공개 옵션을 해제합니다. 게시 이후에는 **Push origin**을 사용합니다.

## 공개 범위와 현재 한계

현재 프로젝트는 검증 결과와 한계를 공개한 개인 포트폴리오입니다. README와 `docs/BASELINE.md`에 기록된 실제 공시 XML 수집 실패 및 RAG 의미 적합성 검토 미완료를 유지합니다. 운영 준비 완료로 소개하지 않습니다.

`evaluation/`에는 재현 근거인 재무 수치와 공시 발췌문이 포함됩니다. 새 실행 결과를 추가할 때는 API 키, 인증 쿼리 문자열, 개인 경로, 불필요한 원문 전체가 없는지 검토합니다. 원문 다운로드와 벡터 DB는 `data/`에 보관합니다.

새 비밀 파일을 만들면 커밋 전에 제외 규칙을 추가하세요. 키가 실제로 게시되었다면 `.gitignore` 추가만으로 해결되지 않으므로 해당 키를 폐기·재발급해야 합니다.
