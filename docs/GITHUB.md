# GitHub 공개 준비

소스 코드, 테스트, 문서, `.env.example`, 의존성 목록과 `evaluation/`의 검증 근거를 공개합니다. `.env.example`의 API 키는 빈 값으로 유지합니다.

`.gitignore`는 실제 `.env`, 가상환경, 캐시, 빌드 결과, 로그, 로컬 DB, `data/`의 공시 원문·벡터 DB, 인증서 및 로컬 도구 설정을 제외합니다. 제외는 파일을 삭제하지 않으며, 이미 커밋한 파일이나 과거 기록에서는 제거하지 않습니다.

## 공개 파일 선택

저장소는 `https://github.com/TechieMoon/finsight-ai`입니다. 소스·테스트·README·설계 문서·Mock 화면과 검토한 최종 검증 기록만 선택해 커밋합니다. 지원자 이력서·포트폴리오·지원서는 개인정보를 포함하므로 저장소 밖에 보관합니다.

공개용 JUnit 기록에서는 hostname을 제거하고 테스트 파일 경로를 저장소 상대 경로로 바꿉니다. 중간 실패 실험은 제외하며 10월 29일 Baseline의 수집 실패는 역사적 근거로 보존합니다. 공개용 로그의 환경 식별 정보 정리는 테스트 상태나 수치를 바꾸지 않습니다. 기존 Git 이력은 강제로 재작성하지 않습니다.

## 공개 범위와 현재 한계

현재 프로젝트는 검증 결과와 한계를 공개한 개인 포트폴리오입니다. 2026-10-29 XML 수집 실패는 과거 Baseline으로 보존하며, 2026-10-31 수정·재검증 결과는 `docs/XML_REPAIR.md`로 구분합니다. RAG 사람 정답 검토는 미완료이며 운영 준비 완료로 소개하지 않습니다.

`evaluation/`에는 재현 근거인 재무 수치와 공시 발췌문이 포함됩니다. 새 실행 결과를 추가할 때는 API 키, 인증 쿼리 문자열, 개인 경로, 불필요한 원문 전체가 없는지 검토합니다. 원문 다운로드와 벡터 DB는 `data/`에 보관합니다.

새 비밀 파일을 만들면 커밋 전에 제외 규칙을 추가하세요. 키가 실제로 게시되었다면 `.gitignore` 추가만으로 해결되지 않으므로 해당 키를 폐기·재발급해야 합니다.
