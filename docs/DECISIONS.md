# 기술적 의사결정

## 1. 단일 LangGraph + 명시적 도구 호출

MVP 질문의 회사·연도·지표 범위가 작아 규칙 기반 분류가 재현 가능하고 비용이 적다.
State는 요청, 경로, 기업, 연도, 원시 재무정보, 계산 결과, 근거, 경고, trace를 가진다.
조건부 edge가 재무 질문과 공시 질문을 분기한다. 각 노드가 도구를 호출한다.
LLM이 임의 도구/URL/코드를 선택하는 에이전트는 구현하지 않았다.
장점은 감사 가능성, 단점은 언어 변형 및 복잡한 복합 질문 지원의 한계다.

## 2. 수치 답변은 LLM이 생성하지 않는다

금액은 Decimal로 보존하고 JSON에 문자열로 전달한다. UI 차트에만 수치형 변환을 사용한다.
분모가 0/결측이면 비율 없음, 전기가 적자면 흑자 전환 또는 적자 지속 상태를 출력한다.
음수 당기 영업이익의 영업이익률은 음수 그대로 표시한다.
금액·URL·접수번호는 서버가 구성한다. 실제 LLM은 공시 원문에서 연속 인용문만 선택한다.
LLM structured output의 인용문이 원문 substring이 아니면 폐기한다.
문장 생성형 종합 요약보다 표현력은 낮지만 근거 추적이 명확하다.

## 3. 기간·회계 기준의 경계

11011(사업보고서), bsns_year, CFS/OFS를 명시한다. 손익계산서 IS/CIS의 thstrm_amount만 사용한다.
전기/전전기 금액을 합하지 않는다. 동일 계정의 중복 금액이 다르면 거부한다.
계정 ID 우선, 정확한 한글 별칭을 보조로 사용한다. 임의 유사 계정 추정은 하지 않는다.
지원 기업은 12월 결산 회사로 제한한다. 전체 재무제표 API에서 명시적 기간 날짜가 없을 때는
사업연도+연간 코드와 지원 기업의 12월 결산 전제에서 1월 1일~12월 31일을 구성한다.
thstrm_dt가 제공될 때는 12개월 시작/종료일을 검증한다. 회계정책 일치까지 보장하지 않는다.

## 4. 수집과 질의의 분리

공시 수집은 CLI에서만 수행한다. 사용자 질문마다 전체 보고서를 다운로드/임베딩하지 않는다.
공식 API 목록에서 사업연도 제목과 사업보고서 유형을 확인하고 마지막 정정 공시를 고른다.
수집 시점 및 접수번호가 남고, 같은 접수번호를 다시 수집하면 갱신한다.
벡터 DB에 여러 정정본이 있으면 질의 시 가장 최근 접수번호를 사용한다.
수집 이후 새로운 정정본은 자동 반영되지 않는다. 수집 명령을 다시 실행해야 한다.
재무 조회 접수번호와 문서 접수번호가 다르면 정정 가능성 경고를 출력한다.

## 5. RAG 전략

텍스트 900자 / 겹침 150자, cosine 검색, 기업·연도·모드 필터, 상위 3개 청크.
실제 모델별 컬렉션을 분리해 임베딩 차원 혼합을 방지한다. 실제 cosine 거리 기준은 기본 0.6이며
**실제 평가로 보정된 수치가 아니다**. 회수율·정확도 검증 전 임계값의 품질을 주장하지 않는다.
Mock은 문자 bigram 해시 256차원과 별도 임계값 0.95를 사용한다. 의미 검색 평가 대체가 아니다.
문단/표 구조를 활용하지 않는 문자 청크는 표와 문장이 잘릴 수 있다.

## 6. 보안·복원력

- 비밀키: 환경변수와 SecretStr, `.env`/벡터 DB ignore, 클라이언트 응답에 키 포함 금지.
- API: 질문 길이 제한, 허용 기준 enum, 분당 전역 호출 한도, 동시 분석 1개.
- DART: timeout, 네트워크/429/5xx 최대 3회, 재시도도 호출 한도에 포함.
- 외부 오류는 키가 들어간 URL을 포함할 수 있으므로 사용자에게 정제된 오류만 전달.
- ZIP은 메모리에서 제한된 크기만 읽고 파일 경로 추출 금지, XML 엔티티/DTD 거부.
- 입력/공시를 명령이 아닌 JSON 데이터로 전달. 자유 실행 도구 없음.
- LLM 답변은 원문 일치 검사, UI는 공시 텍스트를 plain text로 표시.
- 저장소 장애 시 재무 결과 유지, live 실패 시 mock 자동 대체 금지.

출처 자체의 악성 문장·오해를 유발하는 발췌까지 자동 검증하지는 않는다.
현재 호출 제한은 단일 프로세스 기준이며 인증·다중 인스턴스 쿼터·사용량 관측성은 미구현이다.
